01MANIFESTO · 它是什么

YOU SAY IT. HARDWARE just does it.

它不是一个库，也不是一个 SDK —— 它是一套方法论 + 一张设备注册表。 技能本身不绑定任何特定硬件，你登记过的设备就是它能指挥的全部； 想加新设备，把型号告诉它就行。

01

只读一个文件

控制请求从你开口到命令跑起来，中间只读 devices.json。不读固件源码、不跑 --help、不预先 ping、不问你「确认吗」。

02

不预设工具链

Arduino / PlatformIO / ESP-IDF / MicroPython / 树莓派 Python —— 按你的项目和手头材料现选，而不是硬套一套。

03

用人话汇报

成功就一句话；失败先自己重试一次、ping 一下、读段日志，再用人话告诉你原因和下一步，不甩堆栈。

没有它有万物智能
控制设备 翻文档、跑 --help、读源码，试到能跑为止 说一句「灯板设成红色」，直接执行
接入新模块 自己查资料、对引脚、配环境、写固件 一轮问卷 → 自己选工具链 → 自己烧录 → 自动登记
出错的时候 贴一大段堆栈给你，剩下自己猜 先自己复现 + ping + 读日志，再顺着决策树往下排
交付文档 没有，或者只有一份 README 自动生成单文件 HTML 说明书，能直接给别人看

03REGISTRY · 设备注册表

把 --help 写进注册表。

devices.json 是整套东西的核心：每条命令写清「做什么 / 怎么跑 / 参数是什么」， 技能读一遍就能理解你的口语并敲出正确的命令。检验标准很简单 —— 一个没看过代码的人，只读这份档案就能正确敲出每条命令。

  • devices数组里才是已登记设备；初始为空，_template 只是格式示范，技能绝不会把它当成真设备去执行。
  • aliases口语叫法。「灯板」「灯珠」「RGB灯」都能匹配到同一台设备。
  • commands口语 → 真实命令的映射，相当于把 --help 写进注册表。
  • hardware主控、工具链、信号引脚、烧录串口、供电注意事项 —— 烧录流程直接读这里。
  • manual交付说明书的路径，说「打开说明书」就打开它。

通过技能接入的新设备会自动写好这一整段，你不用手填。
已装过？devices.json 是本地文件（已被 .gitignore 排除），git pull 不会覆盖你的设备数据。

devices.jsonJSON · 本地文件 · 不入库
{
  "devices": [{
    "name": "led_matrix_8x8",
    "aliases": ["灯板", "灯珠", "RGB灯"],   // 口语叫法，技能靠它匹配
    "control": {
      "cli": "pc/led_cli.py",
      "transport": "tcp:8888"
    },
    "global_options": {                       // 所有子命令通用
      "--ip <地址>": "指定设备 IP，成功一次后自动记住"
    },
    "commands": {
      "color": {
        "desc": "全部灯珠设为同一颜色；关灯就是 0 0 0",  // 一句话说做什么
        "run":  "python pc/led_cli.py color {r} {g} {b}", // 真实命令模板
        "args": {                                   // 占位符的含义/范围/默认值
          "r": "红 0-255", "g": "绿 0-255", "b": "蓝 0-255"
        }
      }
    },
    "hardware": { "mcu": "ESP32-S3", "toolchain": "arduino" },
    "manual": "docs/manual.html"
  }]
}
从你开口，到灯亮起来 —— 中间只读一个文件 你的话注册表执行汇报
04INSTALL · 安装

两条命令， 然后 just say it.

技能在会话启动时加载 —— 装完要新开一个会话才会生效。 不想自己敲？把一句话丢给任意 Claude Code 会话，让它替你装完。

terminal · bash 
# 1 · 克隆到用户级 skills 目录，Claude Code 自动发现
#     Windows 下 ~ 就是 C:\Users\<你的用户名>
$ git clone --depth 1 https://github.com/AiFLYF/wuwu-intelligence.git \
    ~/.claude/skills/wuwu-intelligence

# 2 · 复制设备注册表模板（本地文件，不入库）
$ cp ~/.claude/skills/wuwu-intelligence/devices.json.example \
     ~/.claude/skills/wuwu-intelligence/devices.json
  • 也可以克隆到某个项目的 .claude/skills/ 下，仅在该项目内生效
  • 已经装过？进目录 git pull 更新即可，devices.json 不会被覆盖
  • 需要本机有 git；控制脚本需要 Python 3（Python 不是技能本身的依赖）
