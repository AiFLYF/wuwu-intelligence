# 创意工坊(流程 E):有模块,不知道做什么

用户说"我有几个模块不知道能干嘛""这个能做点什么好玩的"时走这里。目标:**帮用户把模糊想法变成可选方案,由用户拍板**,然后无缝接入流程 B。

## 第 1 步:一轮选择题(最多 4 题)

优先用 AskUserQuestion,没有就编号列表。

| 题 | 形式 | 选项示例 |
|---|---|---|
| 手上有哪些东西? | 填空 / 多选 | ESP32-S3 / 灯带 / 舵机 / 温湿度 / 屏幕 / 摄像头 / 麦克风 / 其他(填) |
| 用在哪? | 单选 | 书桌 / 卧室 / 客厅 / 户外阳台 / 送人当礼物 / 随便 |
| 想要什么感觉? | 单选 | 实用(解决一个具体麻烦) / 好玩酷炫 / 学东西练手 / 都行 |
| 投入多少? | 单选 | 一晚上搞定不花钱 / 一周内可买点小配件 / 不限 |

## 第 2 步:深度思考,出 2-3 个方案

思考时逐项过一遍:
- 每个模块的能力(输入还是输出?能感知什么?能表现什么?)
- 模块两两组合能产生什么"感知 → 反应"的闭环
- 用户场景里真实存在的小麻烦(忘关灯、不知道温度、快递到没到、久坐)
- 已登记设备(devices.json)能否加入组合

方案按"最推荐"排前,每个方案固定五行:
```
方案 1:XXXX(一句话说做出来是什么)
- 效果:用户看到 / 听到 / 感受到什么
- 用到:手头哪些模块
- 还缺:要买什么(没有就写"不用买")
- 难度 / 耗时:★☆☆ 一晚上 / ★★☆ 一个周末 / ★★★ 一周
- 之后能加:一两个延伸方向
```

最后一句:"选一个我就开始,或者告诉我你想改哪里"。

## 第 3 步:用户选定 → 进流程 B

- 把已知信息(模块、控制方式、主控)带过去,流程 B 问卷里对应的题跳过
- 方案里"还缺"的东西,先做能做的部分,缺件到货再补
